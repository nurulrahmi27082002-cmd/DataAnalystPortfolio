# Data Analyst Portfolio

Website portofolio profesional untuk menampilkan tiga studi kasus Data Analyst:
1. Retail Sales Performance Analysis
2. Customer Behavior & Retention
3. E-Commerce Business Intelligence

## Demo lokal
1. Download atau clone repositori.
2. Buka `index.html` di browser. Tidak membutuhkan build step atau framework.

## Publikasikan dengan GitHub Pages
1. Buat repositori publik di GitHub, misalnya `data-analyst-portfolio`.
2. Upload semua file dan folder proyek.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu proses deployment selesai. URL website akan muncul di halaman Pages.

## Personalisasi sebelum publikasi
- Ganti `Nama Kamu` dengan nama profesional.
- Ganti tautan LinkedIn, GitHub, dan email pada `index.html`.
- Isi bagian About dengan pengalaman dan tujuan yang benar.
- Ganti placeholder dashboard dengan visual dari hasil analisis nyata.
- Isi folder proyek dengan SQL, notebook, dokumentasi, dan tautan dataset yang sah.

## Catatan integritas
Semua angka bertanda placeholder atau visual ilustratif bukan hasil bisnis aktual. Jangan mengklaim peningkatan revenue, profit, atau retensi tanpa analisis yang mendukungnya.
