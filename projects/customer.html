DATA ANALYTICS / CASE STUDY

Customer Behavior & RFM Segmentation

Excel · Python · SQL · Power BI · Word · PowerPoint

← Back to all projects
Status: Project Blueprint

Halaman ini adalah rencana studi kasus. Belum ada analisis nyata atau hasil terverifikasi; tambahkan temuan setelah proyek dikerjakan.

01 / Business Question

Siapa pelanggan bernilai tinggi, pelanggan berisiko churn, dan bagaimana menyusun segmentasi pemasaran yang lebih tepat?

02 / Data Source

Dataset transaksi pelanggan anonim (misalnya UCI Online Retail).

03 / Key Metrics

Recency, frequency, monetary value, repeat purchase rate, segment share.

04 / Analysis Workflow

Excel: pemeriksaan kualitas data; SQL: metrik transaksi per pelanggan; Python: RFM scoring dan EDA; Power BI: visual segmentasi dan cohort.

05 / Expected Deliverables

Buat segmen RFM, evaluasi pola repeat purchase, dan rumuskan rekomendasi kampanye per segmen.

06 / Files & Reports

Tambahkan berkas analisis ke folder deliverables/customer/, lalu perbarui tautan di bawah.

  • Excel workbook (.xlsx)
  • Python notebook (.ipynb)
  • SQL queries (.sql)
  • Power BI dashboard (.pbix atau tautan publik)
  • Microsoft Word report (.docx / PDF)
  • PowerPoint presentation (.pptx / PDF)

Insight & recommendations: isi dengan hasil analisis yang dapat diverifikasi dan batasan data.
