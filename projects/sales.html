DATA ANALYTICS / CASE STUDY

Sales Performance & Revenue Analytics

Excel · Python · SQL · Power BI · Word · PowerPoint

← Back to all projects
Status: Project Blueprint

Halaman ini adalah rencana studi kasus. Belum ada analisis nyata atau hasil terverifikasi; tambahkan temuan setelah proyek dikerjakan.

01 / Business Question

Bagaimana tren penjualan, kategori dan wilayah mana yang berkontribusi paling besar, dan peluang pertumbuhan apa yang dapat diprioritaskan?

02 / Data Source

Dataset transaksi retail (misalnya Sample Superstore atau dataset transaksi publik berlisensi jelas).

03 / Key Metrics

Revenue, profit margin, order volume, average order value, monthly growth.

04 / Analysis Workflow

Excel: validasi dan PivotTable; SQL: agregasi penjualan, JOIN dan window function; Python: cleaning dan EDA; Power BI: dashboard KPI dan tren.

05 / Expected Deliverables

Identifikasi tren bulanan, produk unggulan, wilayah dengan margin rendah, dan usulkan prioritas perbaikan.

06 / Files & Reports

Tambahkan berkas analisis ke folder deliverables/sales/, lalu perbarui tautan di bawah.

  • Excel workbook (.xlsx)
  • Python notebook (.ipynb)
  • SQL queries (.sql)
  • Power BI dashboard (.pbix atau tautan publik)
  • Microsoft Word report (.docx / PDF)
  • PowerPoint presentation (.pptx / PDF)

Insight & recommendations: isi dengan hasil analisis yang dapat diverifikasi dan batasan data.
